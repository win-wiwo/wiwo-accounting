Roles & Permissions

Staff
Requester
  • Create / edit PRs (Draft only)
  • Submit PRs
  • Recall PRs (before L3)
  • Cancel PRs (before L3)
  • Respond to Returned for Info
  • View own PRs
Department Head
Requester + Level 1 Approver
  • All Staff capabilities
  • Submits skip to COO (Level 2)
  • Approve / Reject / Return\nat Level 1 (own dept only)
  • Review canvass (QUOTED)
  • Cannot approve own PRs
Procurement Officer
Canvassing
  • View PRs in Pending Quotation
  • Upload canvass / supplier quotes
  • Select winning supplier
  • Submit quotation
  • Return for Info (to requester)
COO
Level 2 Approver
  • View all PRs at Level 2
  • Approve / Reject / Return
  • Requires comments on Reject/Return
  • Cannot approve own PRs
CEO
Level 3 Approver
  • View all PRs at Level 3
  • Approve / Reject / Return
  • Requires comments on Reject/Return
  • Cannot approve own PRs
  • Final approval = APPROVED
Admin
System Admin
  • Manage users & departments
  • Configure PR numbering
  • View all PRs (read-only)
  • Cannot create PRs
Accounting
Finance
  • View approved PRs
  • Manage purchase orders
  • Generate reports

Status Reference

Draft Created, not yet submitted. Editable.
Pending Quotation Awaiting procurement canvass (has procurement items).
Returned for Info Procurement needs more info from requester.
Quoted Canvass submitted; awaiting Dept Head approval of quotes.
Level 1 Review Awaiting Department Head approval.
Level 2 Review Awaiting COO approval.
Level 3 Review Awaiting CEO approval.
Returned Sent back by an approver for revision. Editable again.
Approved Final approval granted (CEO). Terminal state.
Rejected Denied by an approver. Terminal state.
Cancelled Withdrawn by requester. Terminal state.

Key Business Rules

Dept Head skip: When a Department Head submits their own PR, it bypasses Level 1 review (since they are the Level 1 approver) and goes directly to Level 2 (COO).
Procurement path: Any PR with at least one line item marked as procurement sourcing type goes to Pending Quotation before approval. Items marked online go directly to the approval chain.
Self-approval blocked: No approver can approve a PR they created. This is enforced server-side regardless of role.
Dept Head scope: At Level 1 review, Dept Heads can only act on PRs from their own department.
Recall vs Cancel: Recall returns a submitted PR to Draft (available from L1, L2, Pending Quotation, Returned for Info). Cancel permanently withdraws it (additionally available from Draft itself). Neither is available once Level 3 review has started.
Comments required: Reject and Return actions always require a comment. The API enforces this and will reject the request without one.
Resubmission diff: When a returned PR is resubmitted, the previous submission snapshot is stored so approvers can see what changed (highlighted in the UI as old vs. new values).
